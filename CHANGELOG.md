# Changelog

## 0.1.0 — 2026-10-02

- Initial standalone open-source release of the Hanifi Rohingya ↔ Rohingyalish
  converter and Rohingya Reader Chrome extension.
- Shared conversion engine with JavaScript builds and TypeScript declarations.
- Local font assets, MIT code license, and preserved OFL font notices.
- Independent build, unit checks, local browser fixtures, and extension package
  verification.

The extension's runtime conversion behavior and version remain 0.1.0. Build
paths and development tooling were adapted for this standalone repository.
